# شاشة TV — Shasha TV

مشغل IPTV للآيفون والآيباد: بسيط وسهل وبيوفر في النت.
التطبيق **مشغل بس** ومفيهوش أي قنوات أو محتوى. بتدخل بيانات اشتراكك أنت.

## المميزات

- **دخول بطريقتين:** Xtream Codes (سيرفر + يوزر + باسورد) أو رابط M3U.
  لو رابط الـ M3U فيه `get.php?username=...&password=...` التطبيق بيحوّله لوضع Xtream لوحده، لأنه أسرع وأخف.
- **قنوات مباشرة، أفلام، مسلسلات** متقسمة حسب الأقسام، وفيها بحث.
- **المسلسلات:** المواسم والحلقات، وكل حلقة اتفرجت عليها عليها علامة.
- **تابع المشاهدة:** الفيلم أو الحلقة بتكمل من المكان اللي وقفت عنده.
- **المفضلة:** اضغط مطوّلًا على أي قناة أو فيلم أو مسلسل.
- **عربي وإنجليزي:** بيتغير تلقائيًا حسب لغة الموبايل، وبيدعم الكتابة من اليمين للشمال.
- **بيانات الدخول بتتحفظ في الـ Keychain** (متشفرة).

## توفير النت 📉

| الخاصية | التفاصيل |
|---|---|
| جودة الفيديو | توفير (360p) / متوازن (720p، الافتراضي) / أعلى جودة |
| تحميل مسبق قليل | المشغل مش بيحمّل كتير قدام، فلو قفلت بدري مش بتخسر نت |
| وقف التحميل فورًا | لما تقفل المشغل أو تخرج من التطبيق، التحميل بيقف |
| القوائم محفوظة | قوائم القنوات والأفلام بتتحفظ على الموبايل (من 6 ساعات لأسبوع) |
| تحميل حسب القسم | في وضع Xtream، كل قسم بيتحمّل لوحده لما تفتحه بس |
| الصور | بتتصغّر وبتتحفظ، وممكن تخليها "على الواي فاي بس" أو "أبدًا" |
| وضع البيانات المنخفضة في iOS | الصور مش بتتحمّل لما Low Data Mode يكون شغال |
| من غير دليل برامج (EPG) أو معاينة تلقائية | علشان ميتسحبش نت في الخلفية |

> حد الجودة بيشتغل بس لو السيرفر بيبعت أكتر من جودة (HLS متعدد الجودات). لو البث جودته واحدة، الحد مش هيأثر.

## إزاي تنزّله على الآيفون

مفيش ماك؟ مفيش مشكلة:

1. كل `push` على GitHub بيشغّل **GitHub Actions** (`.github/workflows/build-ios.yml`) اللي بيبني التطبيق على ماك.
2. ادخل على تبويب **Actions** في الريبو ← آخر Run ← نزّل ملف **ShashaTV-unsigned-ipa**.
3. ثبّت الـ IPA على الآيفون بأداة توقيع زي **Sideloadly** أو **AltStore** باستخدام Apple ID عادي (مجاني).
   - مع الحساب المجاني لازم تعيد التوقيع كل 7 أيام. مع حساب Apple Developer (99$ في السنة) المدة سنة، وتقدر تستخدم TestFlight.

لو عندك ماك:

```bash
brew install xcodegen
xcodegen generate
open ShashaTV.xcodeproj
```

بعد كده اختار الـ Team بتاعك من **Signing & Capabilities**، وصّل الآيفون، ودوس ▶︎.

## ملاحظات

- المشغل هو مشغل أبل الأصلي (AVPlayer)، وده بيوفر بطارية ونت. بيشغّل **HLS (m3u8)** و**MP4**.
  القنوات المباشرة بتشتغل بصيغة m3u8 تلقائيًا. **ملفات MKV/AVI مش مدعومة** في مشغل أبل، والتطبيق هيعرض رسالة واضحة لو قابل واحد منها.
- أقل إصدار مدعوم: iOS 16.

## هيكل المشروع

```
  App/        نقطة البداية + حالة التطبيق (الحساب، التشغيل)
  Models/     الموديلز (قناة/فيلم/مسلسل/حلقة، الحساب، الأخطاء)
  Services/   Xtream API، قارئ M3U، الكاش، الصور، الإعدادات، المفضلة

project.yml   إعدادات XcodeGen
```

---

**English:** Shasha TV is a lightweight SwiftUI IPTV player for iOS 16+. It supports Xtream Codes and M3U, with
live TV, movies and series (seasons/episodes), favorites, resume playback, Arabic/English UI, and data-saving
features (bitrate caps, short buffers, list caching, downsampled posters, and Low Data Mode support). Build it with
XcodeGen + Xcode, or download the unsigned IPA from GitHub Actions and sideload it. The app does not provide any content.
